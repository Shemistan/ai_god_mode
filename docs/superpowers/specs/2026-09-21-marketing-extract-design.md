## Перенесено

1. **Гейт документации** — `tools/docs_gate.py` (из `marketing/tools/gate`,
   без столбов roadmap и предметных проверок). Регламент давно требовал «статус
   в шапке», но ничто это не проверяло. Теперь: YAML-шапка `тип/статус/обновлено`,
   статусы из словаря типа, взаимные ссылки spec↔plan, `заменён_на` у ADR,
   уникальные номера ADR, автоиндексы в размеченных блоках. Зовётся из `./check`.
   Существующие спеки и план переведены с bullet-шапки на YAML.
2. **Кодовый гейт по сервисам** — в `./check`: для каждого `app/<svc>/` с
   Makefile — `make check`. В pre-commit только сервисы с изменёнными файлами
   в индексе, при ручном запуске и в `./finish` — все.
3. **Шаблон Go-сервиса** — `templates/go-service/`: Makefile с `check`
   (build → vet → golangci-lint как go tool → test -short) и `.golangci.yml` v2.
4. **Рецепт секретов для CLI** — SECURITY.md: скрипт сам читает файл
   секретов, агент его не открывает (guard блокирует `.env` в командах).
5. **Долгие операции — trigger/status/fetch** — правило в CLAUDE.md. В
   marketing MCP с блокирующим опросом до 600 с вешал сессии.
6. **Грабли** — `docs/грабли.md` + правило в CLAUDE.md.
